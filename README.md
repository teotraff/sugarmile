# Sugarmile: магазин для своего хостинга

Готовый сайт и сервер без внешних зависимостей: один Node.js, встроенная база SQLite. `npm install` не нужен.

## Что внутри
- `public/`: сайт (index.html, картинки товаров, шрифты). Сюда же сохраняются загруженные фото (`public/uploads/`).
- `server.js`: сервер и API: товары и остатки, заказы, подписчики, отзывы, админка.
- `catalog.json`: стартовый каталог (артикулы, цены, остатки, доставка, промокоды). Используется при первом запуске.
- `brand-assets/labels/`: плоские макеты этикеток. Их можно загружать в генераторы изображений как референс.
- `Dockerfile`: для запуска в Docker.

## Запуск за 3 шага
1. Нужен Node.js 22.13 или новее (`node -v`).
2. Создайте `.env` из примера и задайте длинный секретный ключ админки:
   ```bash
   cp .env.example .env
   node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"   # вставьте результат в ADMIN_TOKEN
   ```
3. Запустите:
   ```bash
   npm start
   ```
   Сайт откроется на http://localhost:3000, админка на http://localhost:3000/#admin (вход по ADMIN_TOKEN).

## Деплой
- **VPS (Ubuntu и т.п.):** скопируйте папку на сервер, запустите через `pm2 start "npm start" --name sugarmile` или systemd. Поставьте перед ним Nginx или Caddy с HTTPS и проксируйте домен на порт 3000.
- **Render, Railway, Fly.io:** создайте Node-сервис из этой папки. Команда запуска `node server.js`, переменная `ADMIN_TOKEN` задаётся в настройках. Подключите постоянный диск к `data/` и `public/uploads/`, иначе база сбросится при перезапуске.
- **Docker:** `docker build -t sugarmile . && docker run -p 3000:3000 -e ADMIN_TOKEN=... -v $PWD/data:/app/data -v $PWD/uploads:/app/public/uploads sugarmile`

## Подключение оплаты
В `server.js` есть функция `createPayment(order)`. Она вызывается, когда заказ уже сохранён, а сток зарезервирован. Верните из неё ссылку на оплату, и покупателя перенаправит туда. В комментарии рядом есть готовый пример для Stripe Checkout. После оплаты вызовите `markPaid(orderId)` из вебхука платёжки, обработчик-заготовка: `/api/payments/webhook`.

Цены, скидки и доставку сервер всегда пересчитывает сам: подменить цену из браузера нельзя.

## Как устроены данные
- **Остатки:** списываются в момент заказа (в транзакции, перепродать нельзя), возвращаются при отмене заказа в админке.
- **Email:** собираются из попапа, формы рассылки, checkout (галочка согласия) и «Сообщить о поступлении». В админке их можно выгрузить в CSV для Klaviyo, Mailchimp или Shopify Email.
- **Отзывы:** покупатели отправляют их с сайта, публикуете вы в админке. Рейтинг считается только по опубликованным. Если email отзыва совпадает с оплаченным заказом, отзыв автоматически помечается «Verified buyer».
- **Фото:** вкладка Photos в админке заменяет рендер товара вашим фото.
- **Бэкап:** достаточно копировать файл `data/store.db` и папку `public/uploads/`.

## Перед запуском проверьте
- Цены, вкусы и состав в `catalog.json` и в `public/index.html` (блоки Supplement/Nutrition Facts, FAQ, политики). Тексты политик возврата и конфиденциальности — шаблон, их стоит согласовать с юристом.
- Email поддержки: найдите в `public/index.html` строку `supportEmail: ""` и впишите адрес.
